## 说明

所用技术栈：

- .NET 10 / C#
- WPF（Per-Monitor V2 DPI）
- [NAudio](https://github.com/naudio/NAudio) 解码与播放
- [TagLibSharp](https://github.com/mono/taglib-sharp) 本地标签与内嵌封面

已支持的平台：

- Windows 10 及以上（x64）

灵感与交互参考了 [HyPlayer](https://github.com/HyPlayer/HyPlayer) 与 [LX Music](https://github.com/lyswhut/lx-music-desktop) 一类第三方播放器的产品形态：本地曲库优先、多源切换、官方登录拿官方音质、明确拒绝破解。

## 功能

### 本地曲库

- 自选文件夹扫描，**不会**自动全盘检索
- 窗口拖入文件夹即可导入
- 支持 `mp3` / `flac` / `wav` / `m4a` / `aac` / `ogg` / `ape` / `wma`
- TagLib 解析标题、艺人、专辑、时长、内嵌封面
- 内嵌歌词与同目录 `.lrc`（含模糊文件名匹配）
- 曲库索引落盘，二次启动直接恢复列表
- 本地自定义歌单、红心收藏、按文件夹浏览

### 在线服务

侧边栏可在 **本地 / 网易云音乐 / QQ 音乐** 之间切换，三套资料库、登录态、固定歌单互相隔离。

| 能力 | 本地 | 网易云 | QQ 音乐 |
|------|:----:|:------:|:-------:|
| 现在就听 / 首页 | ✓ | ✓ | ✓ |
| 搜索歌曲与歌单 | ✓ | ✓ | ✓ |
| 扫码登录 | — | 网易云 App | 手机 QQ / 微信 |
| 每日推荐 | — | ✓ | ✓ |
| 排行榜 | — | ✓ | ✓ |
| 我喜欢的音乐 | ✓ | ✓ | ✓ |
| 用户歌单 / 固定到侧边栏 | 自定义歌单 | ✓ | ✓ |
| 官方歌词（含翻译） | 内嵌 / LRC | ✓ | ✓ |

登录方式：

- 网易云：App 扫码，或在设置中填写 `MUSIC_U`
- QQ 音乐：QQ / 微信扫码，或在设置中填写完整 Cookie（`uin`、`qm_keyst` 等）
- **不会保存账号密码**

当当前平台没有可用的官方播放地址时，播放器会尝试在另一平台检索同名曲目并用 **该平台官方音源** 播放。这不是破解，也不是解灰；对方平台同样没有授权时仍无法播放。

### 播放与视听

- 流式播放、进度记忆、退出后恢复队列与进度
- 顺序 / 列表循环 / 单曲循环，随机播放
- 下一首播放、播放队列
- 沉浸页：专辑取色、流光活色背景、频谱、黑胶 / 圆角封面
- 双语滚动歌词：对齐、字号、非当前句缩放 / 透明度 / 模糊
- 歌词动画：淡入淡出、缩放过渡、发光脉冲、波浪位移
- 主题：深色 / 浅色 / 跟随系统；可降低透明以减轻性能负担

## 音质

在线音质由 **对应平台账号权益** 决定，本软件只请求官方接口并按失败档位回退。

网易云（设置 → 音质偏好）：

| 档位 | 说明 | 大致要求 |
|------|------|----------|
| `jymaster` | 超清母带 192 kHz / 24 bit | SVIP |
| `sky` | 沉浸声 / 空间音频 | SVIP |
| `jyeffect` | 高清环绕声 | SVIP |
| `hires` | Hi-Res 96 kHz / 24 bit | SVIP |
| `lossless` | 无损 SQ FLAC | VIP |
| `exhigh` | 极高 320 kbps MP3 | 登录即可 |
| `higher` | 较高 192 kbps | — |
| `standard` | 标准 128 kbps | — |

QQ 音乐目前走 Web 端公开 vkey，常见为 320k / 128k / 96k AAC，同样取决于登录与会员状态。

本地音乐按原文件播放，不受上述档位限制。

## 常见问题

**为什么有的歌提示没有可播放的官方音源？**  
未登录、无相应会员、或平台侧无版权时，官方接口不会返回播放地址。请登录对应账号，或改听本地文件。本项目不会绕过这一限制。

**高音质没生效？**  
确认已登录、账号权益足够、音质偏好档位匹配。网易云会按档位向下回退；QQ 音乐受 Web 端 vkey 能力限制。

**扫码一直转圈？**  
二维码会过期，点击刷新。公司网络 / 系统代理可能导致登录接口失败。

**本地歌没有封面或歌词？**  
封面优先读内嵌图；歌词优先内嵌，其次同目录 `.lrc`。文件名与标签不一致时，补全标签或把 lrc 改成与音频同名。

**会扫描整个磁盘吗？**  
不会。只扫描你添加或拖入的文件夹。
